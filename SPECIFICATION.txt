## 4. Multi-agent architecture

Implement the following six agents using LangGraph.

### Agent 1: Orchestrator Agent

This is the central coordinator.

Responsibilities:
- Understand the student's request.
- Decide which agents are required.
- Delegate tasks to appropriate agents.
- Maintain shared workflow state.
- Collect and combine agent outputs.
- Decide whether additional agent execution is needed.
- Return the final response.

It must use conditional routing rather than calling every agent for every request.

Example:
Student asks: "Prepare me for my DBMS exam in three days."

The orchestrator should:
1. Identify the task as exam preparation.
2. Call Research Agent to inspect available DBMS material.
3. Call Study Planner Agent to create a three-day plan.
4. Call Tutor Agent to identify important topics and explain difficult concepts if necessary.
5. Call Quiz Agent to generate a diagnostic quiz.
6. Call Performance Agent after the quiz is completed.
7. Combine the outputs into a final personalized preparation plan.

### Agent 2: Research Agent

Responsibilities:
- Search uploaded PDFs through FAISS.
- Retrieve the most relevant chunks.
- Identify relevant topics and subtopics.
- Extract important definitions and concepts.
- Return source document names and page numbers.
- Identify missing information.
- Never invent information from documents.

Tools:
- `search_course_material(query)`
- `get_document_information()`
- `get_relevant_pages(query)`

### Agent 3: Tutor Agent

Responsibilities:
- Explain concepts using retrieved course materials.
- Provide beginner-friendly explanations.
- Give step-by-step explanations.
- Generate examples and analogies.
- Answer follow-up questions.
- Adjust explanation depth based on student preferences.
- Identify prerequisite concepts when necessary.

Explanation modes:
- Simple explanation.
- Detailed explanation.
- Example-based explanation.
- Exam-oriented explanation.

### Agent 4: Quiz Agent

Responsibilities:
- Generate quizzes from uploaded documents.
- Generate MCQs and short-answer questions.
- Provide different difficulty levels.
- Evaluate student responses.
- Explain correct and incorrect answers.
- Calculate scores.
- Identify topics where the student struggles.

Quiz requirements:
- Questions must be grounded in uploaded material.
- Include correct answers and explanations.
- Do not reveal answers before the student submits.
- Save completed quiz results locally.

### Agent 5: Study Planner Agent

Responsibilities:
- Generate personalized study plans.
- Consider available study time and exam dates.
- Divide topics into manageable sessions.
- Prioritize important and weak topics.
- Include revision and practice sessions.
- Adapt plans when quiz performance is poor.

Example:
Create a three-day DBMS exam preparation plan using uploaded PDFs.

### Agent 6: Performance Agent

Responsibilities:
- Analyze quiz scores and historical performance.
- Identify strong and weak topics.
- Track progress across sessions.
- Recommend topics for revision.
- Provide actionable improvement suggestions.
- Communicate weaknesses to the Study Planner Agent.

Use saved JSON learning history as the source of persistent performance data.

## 5. Agentic workflows

Implement these workflows using LangGraph StateGraph, shared TypedDict state, conditional edges, and appropriate nodes.

### Workflow A: Autonomous Exam Preparation

Input:
- Subject.
- Exam date.
- Available study hours.
- Uploaded study materials.

Execution:
1. Orchestrator analyzes the request.
2. Research Agent retrieves and categorizes relevant topics.
3. Study Planner Agent creates a schedule.
4. Tutor Agent identifies concepts that need explanations.
5. Quiz Agent generates a diagnostic quiz.
6. Performance Agent analyzes results after submission.
7. Study Planner Agent updates the plan based on weak areas.
8. Orchestrator presents the final preparation plan.

### Workflow B: Adaptive Learning

1. Student studies a topic.
2. Tutor Agent explains the topic.
3. Quiz Agent tests understanding.
4. Performance Agent evaluates the score.
5. If the score is low, Tutor Agent provides another explanation.
6. Generate a new quiz.
7. If performance improves, move to the next topic.
8. Save progress locally.

Use meaningful conditional routing and avoid infinite loops. Set a reasonable retry limit.

### Workflow C: Revision Kit Generator

Generate:
- Important definitions.
- Key concepts.
- Short revision notes.
- Important questions.
- MCQs.
- Commonly confused concepts.

Ground the generated content in uploaded PDFs and include citations wherever possible.

### Workflow D: Knowledge Gap Detection

1. Analyze uploaded material.
2. Identify major topics.
3. Analyze quiz results.
4. Compare topic performance.
5. Identify weak or unstudied topics.
6. Generate a prioritized learning recommendation.
